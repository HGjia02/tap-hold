# Tap Hold 生成器（本地版）

纯浏览器、无依赖、免构建的 X / Twitter 长按隐藏图（Tap to Reveal / Kakushie）生成站。所有处理在浏览器 Canvas 本地完成，图片不上传服务器。

## 怎么打开

不需要安装任何东西，两种方式：

**方式一：直接双击**
双击 `index.html`，用浏览器打开即可（编辑器功能完整可用）。

**方式二：本地服务器（推荐，避免个别浏览器对 file:// 的限制）**
```bash
cd tap-hold-site
python3 -m http.server 8765
```
浏览器打开 http://localhost:8765

## 功能

- **隐藏单图模式**：上传一张图，画笔涂出要留在时间线缩略图的区域，其余棋盘格半透明，长按时才出现。
- **A+B 交换模式**：上传图 A（白底时间线显示）和图 B（黑底长按显示），逐像素 alpha 真正互换两张图。
- **三档尺寸预设**：16:9（1200×675）、1:1（1200×1200）、4:5（1080×1350）。
- **实时双预览**：白底时间线 ↔ 黑底查看器并排对比。
- **画笔控制**：大小、显示强度、亮度、对比度，涂抹/擦除，撤销/重做。
- **导出索引色 PNG8**（含 PLTE / tRNS），X 不会重编码。

## 使用流程

1. 首页选模式进入编辑器。
2. 上传图（A，swap 模式再传 B）。
3. 选尺寸，涂抹/调参数，看白底黑底预览。
4. 点「导出 PNG8」下载。
5. **用电脑桌面浏览器登录 x.com 上传**，等 1–2 分钟，到手机时间线长按核对。

## 重要提醒（决定成败）

- **必须桌面浏览器发**：X 手机 App 会把图转成 JPEG，删掉透明通道，效果直接失效。
- **存原图直传**：不要截图、不要经微信/QQ 转发，否则透明层被压平。
- **浅色模式对比弱**：测试时切深色模式，长按更明显。
- **文件 <5MB**：本工具尺寸预设已控制在限制内。

## 技术要点

- **棋盘格方案（隐藏单图）**：保留区实色，隐藏区实色/透明交替，缩略图缩小被平均成淡雾，黑底实色浮现。
- **逐像素 alpha（A+B）**：白底=A、黑底=B，解 `α=(255−W)/(255−B)`、`C=B/α`，再量化到 256 色 PNG8。
- 已知上限：α 三色共用，白底层亮度须高于黑底层，做不出纯白隐藏图。

## 已验证

- 首页/编辑器渲染无控制台报错。
- swap 模式白底显 A、黑底显 B 互换成功。
- hide 模式涂抹、撤销生效。
- 导出文件经校验为 8-bit colormap、颜色类型 3（索引色 PNG8），含 PLTE/tRNS/IDAT。
